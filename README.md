# Les Mots Magiques 🦉

Jeu pour aider les enfants (CP-CE2) à apprendre leurs mots de vocabulaire :
il lit les mots à voix haute, montre les pièges (lettres muettes, doublées,
accents) et les sons à plusieurs lettres (ou, an, eau…), propose 6 jeux,
un parcours guidé et des révisions. L'enfant gagne des étoiles pour habiller
son personnage.

**Jouer en ligne : https://sanpero45.github.io/mots-magiques/**

- Installable sur l'écran d'accueil du téléphone, utilisable sans internet.
- Plusieurs profils d'enfants ; les progrès sont enregistrés sur l'appareil.
- Les listes de mots se saisissent dans l'onglet 🔒 Parents.

Le jeu tient dans un seul fichier (`index.html`), sans dépendance externe.
